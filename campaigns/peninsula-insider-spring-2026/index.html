WEBSITE ACTIVATION PLAN · PROPOSED

Let the idea travel.

Carry the Field Specimens signature across useful moments; do not reskin the whole site.

The website should make each weekly decision discoverable, usable and worth returning to. The anchor remains the source. Supporting surfaces borrow the paper, specimen labels and decision language only when they have a clear job.

Homepage decision band

Add one “This week’s decision” band after the existing This Weekend module. Use the weekly wide specimen, one sentence and one link. Keep the main cover and the rest of the homepage calm.

02 · DECIDE/journal/…

Weekly anchor page

The canonical article carries the full Field Specimens hero, evidence, practical decision and Save action. It is the claim-bearing source every derivative must link back to.

When
First release in each campaign week
Measure
Engagement, source clicks, saves and corrections
03 · DISCOVER/journal/insider-picks-…/

Insider Picks issue cabinet

Add a compact “Decision Cabinet” beneath the current Insider Picks issue introduction: the weekly decision plus two genuinely related picks. Use specimen tabs and labels, not a second hero. The live site has no standalone /picks/ route.

When
Only when the current issue supplies a real connection
Measure
Open, save and onward-pick rate
04 · DISCOVER/whats-on/

What’s On contextual inset

For the holiday and exact-date weeks, place a slim decision card above PI’s Picks. It frames the choice without changing the authority or ordering of the live event list.

When
Weeks 3–4; automatically expire after relevance
Measure
Inset clicks, event saves and + Trip actions
05 · KEEP/me/saved/ · /me/trip/

One-anchor continuation

After a campaign save, offer the next useful action in-page: “One anchor saved. Add one fallback.” Preserve the existing value-first behaviour; no modal or install interruption.

When
Only after a relevant save
Measure
Save-to-Trip progression and return rate
06 · RETURN/dispatch/

The Insider Note echo

The email and on-site Dispatch surface use the week’s email composition and decision line, always linking to the released anchor. The following week closes the loop with the next decision.

When
After anchor read-back; before the relevant moment
Measure
Unique clickers, returns, unsubscribes and complaints
