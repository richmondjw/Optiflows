General Sans is the body and heading family; Space Mono is for compact uppercase metadata, section numbers and button labels. Source examples embed WOFF2 fonts. Preserve those resources or use verified equivalent hosted assets. Do not substitute the older Switzer site style when the user requests this proposal language.

Content column: 880px including 24px side padding. Desktop sections: 72px vertical spacing. Body: 17px, 1.5 line height. Headings: weight 600, slightly tight tracking, fluid sizing. Corner radii: 5px controls, 15px cards, 25px large surfaces. Use dark cover and closing sections, alternating white/paper/mist bodies, electric square label markers, one gradient decision card, pale parameter tiles and rounded tables.

Use the supplied OptiFlows mark and wordmark. No invented illustrations or unnecessary stock imagery. Tables express exact mappings; process cards express staged work. Reflow to one column on narrow screens and allow tables to scroll within their container without page overflow.

Print: A4, colour backgrounds retained, an intentional cover, section page breaks, repeated table headers, no split signature or decision cards where feasible. Hide action controls. Keep approval wording, name, role, date, signature, record ID and proposal version in the signed PDF. The unsigned PDF should contain blank signature lines and identical consent wording.
